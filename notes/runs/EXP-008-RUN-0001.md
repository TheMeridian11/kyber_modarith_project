## Security interpretation and limits

This complements correctness, sampled malformed/noncanonical-input checks, explicit range/scale/narrowing arguments, exercised UBSan and EXP-007 dynamic-flow evidence. The timing harness covers eight bounded paths and two synthetic secret-class profiles, with two process repetitions in one collection session. The IND-CPA decryption stress keys are synthetic encoded coefficients; this is not a full-KEM reencryption/implicit-rejection leakage test. EXP-007 directly tested original/EXP-005/EXP-006; EXP-008 directly tests original/EXP-003/EXP-005.

The observations use ordered RDTSCP intervals in TSC ticks, not core cycles or nanosecond performance claims. No signal at this finite budget does not prove constant time, tiny-leak sensitivity, other secret distributions, other compilers/CPUs, power/EM resistance or fault resistance. Detecting deliberately large positive-control differences does not quantify the smallest detectable real leak. Multiple correlated views/looks and WSL/host effects limit inference; the threshold is diagnostic, not a calibrated family-wise significance level.

The inherited EXP-002 general-dot local-canary tradeoff remains recorded for EXP-003/EXP-005. A quiet timing result does not undo that code-generation observation. No new arithmetic security claim is inferred from throughput or reduction counts.
